# V71 Learnings

1. 独立公开答案只有在答案行、Token 和可反推的官网整数正确数能绑定时，才比普通公开投票多一层约束价值；缺少截图和服务器摘要时仍只能标为 `usable_with_verification`。
2. 完整行的整数分差可以验证一组逐题原文选择：五个近期金标固定为 `-5`，三个候选固定为 `+3` 后，剩余八题必须同时达到理论下界 `-8`。
3. `fc_a_008=D`、`fc_a_014=B`、`fin_a_008=D` 形成条件 97 高价值批次；它们不是三次同模型投票，而是一条外部整行实测方程与三份逐题原文选择的闭合结果。
4. `res_a_006=A` 有外部单题 A/B 自报反馈，但没有公开基线快照或截图，证据等级低于完整 V43 行，提交路线应当分层。
5. 旧 V4-V23 重建列曾把 `fc_a_014=AB` 写成强制标签，但近期直接注册表已证明旧列整体不可继续产生硬标签，不能用旧结论否决新的独立整行证据。
6. 在条件确认 `reg_a_004=C` 后，V68 三题关系可缩为 `reg_a_017=ABC` 与 `ins_a_006=A` 恰一正确；仍不得无证据二选一。

# V112 Learnings

1. 多条公开成绩行不等于多个独立证据源。同一仓库、同一团队的五个版本应视为一个相关家族，不能用行数多数票压过另一个独立家族。
2. 当外部精确分数家族相互冲突时，优先提交所有可行家族共享的强制标签；不共享的标签只能作为家族辨别探针。
3. 同一 Git 提交包含分数记录和完整 CSV，能提升公开自报行的绑定强度；但缺少服务端内容摘要时，仍不能当作直接官网金标。
4. 六次机会不应预先排成无条件列表。每次必须从最新已确认锨点只改一题，再根据最新提交行路由。
5. 逻辑内容相同的 CSV 也要固定 BOM 和换行策略。V112 用哈希回归测试保证 P1/P2 与 V111 字节级一致。

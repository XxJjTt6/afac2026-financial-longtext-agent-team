# V82 Learnings

1. 四个用户指定的本地单选答案对应同一官网分数时，不能直接说官方无合法金标；严格结论是条件二分：若本地绑定正确但闭世界精确匹配模型不可行，则评分器需要 no-match/忽略/规范化异常状态；若合法金标、qid计分和确定性精确匹配契约整体成立，则至少一条绑定或成绩观测有误。
2. `OTHER_ANSWER` 只在“仍有未观测合法答案”时存在不够安全；即使所有合法答案已观测，也必须永久保留“无合法金标/不计分”潜状态。
3. V63 的 anchor94、V75 的三题恰一错、V79 的 B/D 判别树都依赖同一个错误前提，因此不是彼此独立的证据链。
4. 在用户见证的绑定成立时，V80=93 将 V68 相对基线的贡献从旧算式 -2 修正为 -1；旧的“三个替换全错”和“旧答案恰一错”仍可能，但都不再由方程强制。
5. 官网单题对照的 0 贡献只说明两个提交答案命中状态相同；当评分器允许 no-match 状态时，不能用穷尽选项把剩余答案晋级为正确。

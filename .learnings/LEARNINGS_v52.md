# V52 Learnings

1. 官网新反馈优先于所有离线概率、陪审票数和条件投影。
2. 条件100只表示一组假设下的算术结果，不能作为“当前最佳”或预计分数。
3. 对抗门禁失败后，候选必须自动禁止晋级，不能依赖最后回复时人工记住限制。
4. 同一模型的跨提示一致性不是独立标注者一致性；方向字段错误时票数必须作废。
5. 最后机会不得捆绑多个未知标签。单题探针才能保留归因价值。
6. V51 的精确反馈证明七个新答案全部错误：六题由对变错，一题两版都错。
7. `fin_a_016=AD` 在提交前已有直接文本反证，失败门禁后仍提交属于决策错误。
8. 新脚本执行仓库内模块前必须把仓库根目录加入 `sys.path`；V52脚本V1遗漏该步骤，
   V2已另起文件修复。当前环境没有全局pytest，验证命令统一使用 `uv run --with pytest`，
   需要MILP时同时加入 `--with scipy`。

# LEARNINGS V118

1. 六次机会不应将最强两个候选一定拆成两个单题行。“成对行+其中一题的隔离行”能在两次内解出两个有符号贡献，且允许第一次直接达标。
2. `reg_a_014=AC` 的证据强度来自官网和官方 PDF 直接公布，但因为官网与下载数据题干不同，它仍是 QID/版本冲突探针，不是无条件隐藏金标。
3. `fc_a_015=C` 是“隔离 v58 后的直接方程唯一值”，不是语义答案。A/B/C/D 四个合法输出都登记为 93 题的冲突仍然存在。
4. 当一个 96 题锚点已确认时，后续不必每次只改一题。对两道已知基线错题同时尝试候选，任一命中就能到 97，比单题试探有更高的名额效率。
5. 官网只明文公布了一道带标准答案的 QID 样例；本轮 GitHub 搜索没有找到可绑定的 95+或100题公开答案文件，不应伪装成外部金标。

# V73 Learnings

1. 一条公开整行的极值闭合仍可能是同源循环支持；必须用其他来源族单独反证整个候选批次。
2. 8 条公开行分别与近期硬约束相容，却不能同时相容；公开答案行和自报成绩缺少服务器摘要时不能直接并入硬注册表。
3. 全体公开方程的最小冲突只有一题，但存在 `fgrt84:84->83` 与 `yuk20:20->21` 两个等价解释，不能事后挑一个有利解释。
4. YuK 和 Kafka 两个来源族各自独立排除 V71 三题联合批次，因此 V71 的条件 97 路线必须退役。
5. 最小松弛模型产生的三项新异常标签全部撞上直接原文反证；方程可行性不等于可提交真值。

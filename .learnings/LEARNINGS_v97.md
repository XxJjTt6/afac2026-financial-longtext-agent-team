# V97 Learnings

1. 结果截图必须满足“结果时间不早于候选产生时间”，否则不能绑定到该候选。
2. 所有候选复用相同 Token 时，同正确题数的四位小数完全相同，人工绑定非常容易出错。
3. 以后每个正式候选使用不同且很小的 Token 水印，并同时保持 summary 与 100 行 Token 求和一致。
4. 水印只证明服务器评测了某个 Token 配置，不证明答案内容哈希；仍需记录本地 SHA-256、上传文件名和新结果时间。
5. 未得到新时间结果行的 V94/V95/V96 不能进入官网硬约束，也不能用于排除候选答案。
6. 同一轮多个候选必须等待前一轮结果后按决策树选择，不能把条件文件连续上传。

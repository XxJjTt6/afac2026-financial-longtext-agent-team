# V99 Learnings

1. 多选题必须先逐选项判真，再拼成完整标签；不能因为部分子集的公开松弛更低就优先提交部分答案。
2. 最小松弛模型对“从未在公开行出现”的答案存在逃逸偏好：不匹配任何公开行有时反而更容易达到最小误差。
3. `fc_a_004` 的全文逐项结论为 A、C、D 真，B 假，因此 ACD 应在 D 之前测试。
4. `fc_a_014` 的全文逐项结论为 B、C 真，A、D 假，因此 BC 应在 C 之前测试。
5. 直接官网排除一个部分子集并不排除它的真超集。例如 A、CD 都错与 ACD 正确完全相容。
6. 使用 327071、327091、327131、327151、327171 这组较小水印即可改变四位小数，同时比数百 Token 水印更少损失综合分。
7. 弱公开自述若缺少完整上传行与服务器摘要，只能作为风险项，不能推翻可逐项复核的原文事实。

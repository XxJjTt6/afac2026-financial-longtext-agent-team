# V115 Learnings

1. 官网分数截图不等于提交文件身份证明。没有服务器文件摘要时，本地文件绑定只能标记为“用户陈述”。
2. 同一题的所有合法标签都对应相同正确数，是绑定或日志错位的强信号，不能继续用该方程推导答案。
3. 多个公开仓库不是多个官方真值源。先按来源族分开求解，再用原文和独立共识重排，不能把矛盾成绩行强行做联立硬约束。
4. 条件后验质量取决于假设和先验，不是官网正确概率。`res_a_004=AB` 虽然方程质量低，但原文和公开共识都强，不应被单一模型质量压到末位。
5. 每个新提交文件必须同时记录 SHA-256、答案 diff、Token 总数和各正确数的综合分指纹。
6. 三个两两组合探针可在 3 次提交内求出 3 个单题改动的 `-1/0/+1` 贡献，且任意两个改动都正向时可直接达到 97 题。

# V79 Learnings

1. 两个互斥的最小一分松弛模型给出相同局部解，比只选 `fgrt84` 或 `yuk20` 单行更鲁棒，但仍受制于公开分数与答案行缺少服务器摘要。
2. `anchor94 + ins_a_006=B` 的价值不只是一题变化：官网整数正确题数 93/94/95 分别区分 A 正确、A/B 都错、B 正确，且相对当前实测最佳 93 没有题数下行。
3. P1=93 会直接反证公开最小松弛模型的 `ins_a_006=A 必错` 结论。因此同一分支上不能继续照搬该模型的 `reg_a_004/reg_a_017` 身份；应先提交字节级相同的 94 题锚点。
4. 语义上可解释不等于隐藏标签正确，代数上强制也不等于来源绑定真实。V79 把二者分开记录，不再用模型 confidence 或整齐的方程替代来源可信度。
5. 有限提交机会应优先选择“结果分支少、每个分支可行动、最坏不低于实测最佳”的候选，而不是最大化一次性改题数。

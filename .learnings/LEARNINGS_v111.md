# V111 Learnings

1. 评分目标是隐藏答案键，不是重建的严格原文真值。当精确分数方程与原文语义冲突时，必须同时保留“隐藏键”和“原文真值”两个字段，不得用后者覆盖前者。
2. 对不可行的官网账本，先枚举最小绑定删除集。本轮中 `v58` 是唯一单行修复；把所有冲突泛化为“评分不敏感”会丢失更强的定位证据。
3. 外部答案行只有在“完整 CSV + 真实 Token + 分数指纹恰好指向整数正确题数”时才进入方程。仍必须标记为无服务端内容摘要，不冒充直接官网金标。
4. V110 的 `fc_a_004=ACD` 在加入独立精确分数行后被联合方程排除，所以候选排序必须在新证据进入后重算，不能沿用旧版的语义排序。
5. 当已经有稳定的 95 题锚点时，重复上传字节相同的控制文件不产生任何题级信息。新机会应先用于已被方程强制的单题修复。
